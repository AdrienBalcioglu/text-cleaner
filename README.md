# Text Cleaner

Paste messy text, get it back clean: spacing, broken lines, tracking links, quotes, case.

## Features

- Collapse spaces and blank lines, join lines broken by a PDF
- Remove tracking parameters from links (`utm_*`, `fbclid`, `gclid` and others)
- Straighten quotes, strip HTML, remove emoji, invisible characters and duplicate lines
- Case conversion and live character, word and line counts

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build.

The text you paste is processed in the page and is never sent anywhere. Only your choice of options is remembered.

## Stack

HTML, CSS and JavaScript in a single file. No dependency.
